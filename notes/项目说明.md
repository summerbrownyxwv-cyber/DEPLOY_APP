# 寻艾官网

唯一维护目录：桌面的“寻艾官网”。

## 四个大类

- assets：当前网站使用的图片、视频、字体、SVG 与响应式图片，按用途分类。
- content：正式页面的文案维护索引及后续独立内容文件。
- notes：项目维护与部署说明，不参与网页加载。
- website-code：网页入口、样式、交互、设计变量、构建与预览脚本。

根目录的 index.html 是打开网站的快捷入口。package.json、package-lock.json、vercel.json 等是运行和部署配置，保留在根目录。

## 查看与发布

使用 Node.js 22 或以上版本。在项目目录执行 `npm run dev` 可查看源码；执行 `npm run build` 后，用 `npm run preview` 查看发布结果。

唯一发布目录：website-code/dist。它由当前源码生成，不是另一版网站，不要在其中直接修改代码。部署时仅上传这个目录内的内容；Vercel 已配置该输出目录。

发布目录只包含根入口、运行代码和当前素材，不包含 Git、说明文档、构建脚本或旧备份。
